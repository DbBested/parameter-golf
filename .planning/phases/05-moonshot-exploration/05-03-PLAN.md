<objective>
Run the test-time training (TTT) experiment -- LoRA adaptation during evaluation.

Purpose: TTT adapts the model to the validation data distribution at eval time by applying LoRA (rank-4) to Q/V projections and training on already-evaluated tokens. An existing competition submission (2026-03-17_LoRA_TTT) provides a proven implementation pattern. On a weak base model (1.19 BPB), TTT added -0.003 BPB. Our stronger base (1.14 BPB) may see diminishing returns, but the technique is orthogonal to training improvements and worth testing.

Output: A training run that trains the base model normally, then performs TTT-enhanced evaluation, with BPB comparison to standard eval.
</objective>

       def forward_with_lora(model, x, lora_modules):
           # Before forward: add LoRA deltas to weight matrices
           originals = {}
           for name, lora in lora_modules.items():
               layer = get_layer(model, name)
               originals[name] = layer.weight.data.clone()
               # LoRA delta: A^T @ B^T applied to weight

       Actually, the simplest approach for our model: since we're not batching across documents (we process one sequence at a time for TTT), use a straightforward approach:

       ```python
       def eval_val_ttt(args, base_model, rank, world_size, device,
                        val_tokens, base_bytes_lut, has_leading_space_lut, is_boundary_token_lut):
           """Sliding window eval with per-document LoRA TTT."""
           seq_len = args.train_seq_len
           stride = args.eval_stride
           chunk_size = args.ttt_chunk_size
           total_tokens = val_tokens.numel() - 1

           # Create LoRA params for Q and V in all blocks
           lora_params = {}
           for i, block in enumerate(base_model.blocks):
               for proj_name in ['c_q', 'c_v']:
                   proj = getattr(block.attn, proj_name)
                   in_f, out_f = proj.weight.shape[1], proj.weight.shape[0]
                   A = torch.zeros(args.ttt_lora_rank, in_f, device=device, dtype=torch.float32, requires_grad=True)
                   B = torch.zeros(out_f, args.ttt_lora_rank, device=device, dtype=torch.float32, requires_grad=True)
                   nn.init.kaiming_uniform_(A, a=math.sqrt(5))
                   lora_params[f"blocks.{i}.attn.{proj_name}"] = (A, B, proj)

           all_lora_tensors = []
           for key in lora_params:
               A, B, _ = lora_params[key]
               all_lora_tensors.extend([A, B])
           lora_opt = torch.optim.Adam(all_lora_tensors, lr=args.ttt_lora_lr)

           def reset_lora():
               for key in lora_params:
                   A, B, _ = lora_params[key]
                   with torch.no_grad():
                       nn.init.kaiming_uniform_(A, a=math.sqrt(5))
                       B.zero_()

           def apply_lora():
               """Temporarily add LoRA deltas to weights."""
               originals = {}
               for key, (A, B, proj) in lora_params.items():
                   originals[key] = proj.weight.data.clone()
                   delta = (B @ A).to(proj.weight.dtype)
                   proj.weight.data += delta
               return originals

           def restore_weights(originals):
               for key, (A, B, proj) in lora_params.items():
                   proj.weight.data = originals[key]

           # Process windows with TTT
           # ... (standard sliding window loop, but after scoring each window,
           #      do a training step on the LoRA params)
           # Reset LoRA when encountering document boundaries (BOS token = 1)
       ```

       The detailed implementation should follow the pattern from the TTT submission but adapted to our sliding window eval. Key points:
       - Use `torch.no_grad()` for scoring, `torch.enable_grad()` for LoRA training
       - Score window first (accumulate BPB), then train LoRA on same window
       - Reset LoRA at document boundaries
       - Only apply to rank 0 for distributed eval (each rank processes its partition)

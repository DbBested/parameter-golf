  <action>
    1. Create scripts/eval/multiseed_eval.py:

       `analyze_seeds(bpb_values, baseline_bpb=None)`:
       - Takes list of float BPB values (one per seed)
       - Computes: n_seeds, mean_bpb, std_bpb (ddof=1), min_bpb, max_bpb
       - If baseline_bpb provided (list of floats): runs scipy.stats.ttest_ind(bpb_values, baseline_bpb, alternative="less") to test if new < baseline
       - Returns dict with all stats + optional t_statistic, p_value, mean_improvement, significant_p01 (bool)
       - Prints formatted summary:
         ```
         === Multi-Seed Evaluation ===
         Seeds: 3
         Mean BPB: 1.2242 +/- 0.0018
         Range: [1.2224, 1.2260]
         Status: REPRODUCIBLE (std < 0.003)
         ```

       `collect_seed_results(result_dir, run_id_prefix)`:
       - Reads experiments.jsonl from result_dir
       - Filters records where run_id starts with run_id_prefix (e.g., "baseline_seed")
       - Returns list of val_bpb values
       - Prints warning if fewer than 3 seeds found

       CLI with `--result-dir`, `--run-id-prefix`, `--baseline-prefix` (optional for comparison)
       Requires: numpy, scipy

    2. Create scripts/eval/timing_calibration.py:

       `parse_timing_from_log(log_path)`:
       - Reads a SLURM output log file
       - Extracts wall-clock training time (look for patterns like "Training time:", "wall_time:", or elapsed time between start/end markers)
       - Returns wall_time_seconds (float)
       - NOTE: Read train_gpt.py first to see exactly what timing info it prints

       `estimate_h100_time(h200_seconds, ratio=1.35)`:
       - Multiplies h200_seconds by ratio
       - Default ratio 1.35 (conservative middle estimate between 1.3 and 1.45)
       - Prints:
         ```
         === H200-to-H100 Timing Estimate ===
         H200 measured:    420.0 seconds (7.00 minutes)
         Slowdown ratio:   1.35x
         H100 estimated:   567.0 seconds (9.45 minutes)
         H100 budget:      600.0 seconds (10.00 minutes)
         Margin:           33.0 seconds (0.55 minutes)
         Status: WITHIN BUDGET
         ```
       - Returns dict with h200_seconds, h100_estimated, budget_seconds (600), margin_seconds, status ("WITHIN BUDGET" or "OVER BUDGET")

       `calibrate_from_experiments(result_dir, run_id_prefix="baseline")`:
       - Reads experiments.jsonl, filters by prefix
       - Extracts wall_time_seconds from each matching record
       - Computes mean H200 time and estimates H100 time
       - Returns timing stats dict

       CLI: `--result-dir`, `--run-id-prefix`, `--ratio FLOAT`, `--log-path PATH`

    3. Create scripts/eval/ablation_runner.py:

       This is the framework for Phase 2+ ablation studies. For now it provides:

       `run_ablation(base_config, technique_name, technique_enabled, sbatch_template, submit_dir, dry_run=False)`:
       - base_config: dict of baseline hyperparameters
       - technique_name: string identifying the technique (e.g., "bigram_hash", "muon", "int6_qat")
       - technique_enabled: bool (True = with technique, False = without)
       - Creates a modified SLURM script with environment variables for the config
       - If not dry_run: submits the job via subprocess and returns job ID
       - If dry_run: prints the command that would be run
       - Returns dict with job_id, config, technique_name, enabled

       `compare_ablation_results(result_dir, baseline_prefix, ablation_prefix)`:
       - Loads baseline and ablation BPB values from experiments.jsonl
       - Computes mean difference and p-value (scipy.stats.ttest_ind)
       - Prints formatted comparison:
         ```
         === Ablation: bigram_hash ===
         Baseline mean BPB:  1.2242
         With technique:     1.2180
         Improvement:        0.0062
         p-value:            0.0034
         Significant (p<0.01): YES
         ```
       - Returns dict with baseline_mean, ablation_mean, improvement, p_value, significant

       CLI: `--result-dir`, `--technique`, `--baseline-prefix`, `--ablation-prefix`, `--dry-run`

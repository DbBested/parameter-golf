  <action>
    1. Create scripts/eval/check_artifact_size.py:

       `check_artifact_size(model_path, code_paths, limit=16_000_000, margin=500_000)`:
       - model_path: path to compressed model file (e.g., final_model.int8.ptz)
       - code_paths: list of code file paths (e.g., ["train_gpt.py"]) -- sum their UTF-8 byte sizes
       - Reads model file size via os.path.getsize()
       - Reads each code file, encodes to UTF-8, sums byte lengths
       - Computes total = model_bytes + code_bytes
       - Prints formatted report:
         ```
         === Artifact Size Report ===
         Model:  15,234,567 bytes (15.23 MB)
         Code:      18,432 bytes (18.4 KB)
         Total:  15,253,000 bytes (15.25 MB)
         Limit:  16,000,000 bytes (16.00 MB)
         Budget:    747,000 bytes (0.75 MB)
         Status: PASS
         ```
       - Returns dict: {"model_bytes": int, "code_bytes": int, "total": int, "limit": int, "budget_remaining": int, "status": "PASS"|"FAIL"|"WARNING"}
       - Status is "FAIL" if total > limit, "WARNING" if budget_remaining < margin, "PASS" otherwise
       - sys.exit(1) if status is "FAIL"

       CLI: `--model PATH --code PATH [PATH ...] --limit INT --margin INT`
       Default limit: 16000000, default margin: 500000

    2. Create scripts/eval/validate_bpb.py:

       `validate_baseline_bpb(measured_bpb, expected=1.2244, tolerance=0.005)`:
       - Computes diff = abs(measured_bpb - expected)
       - Prints:
         ```
         === BPB Validation ===
         Measured: 1.2240
         Expected: 1.2244
         Diff:     0.0004
         Tolerance: 0.0050
         Status: PASS
         ```
       - Returns bool (True if diff <= tolerance)
       - If diff > 0.01: prints diagnostic note about potential training issues

       CLI: `--measured FLOAT --expected FLOAT --tolerance FLOAT`
       Defaults: expected=1.2244, tolerance=0.005

    3. Update scripts/slurm/train_baseline.sbatch to add post-training validation calls:
       After the `torchrun` command, add:
       ```bash

       cd "${SLURM_SUBMIT_DIR}"

       # Check artifact size
       python scripts/eval/check_artifact_size.py \
           --model repo/final_model.int8.ptz \
           --code repo/train_gpt.py

       # Log experiment (will need manual BPB entry or parse from training output)
       echo "=== Training complete. Check logs for val_bpb ==="
       ```

    Both scripts must:
    - Use `#!/usr/bin/env python3` shebang
    - Use only Python stdlib (os, sys, argparse, pathlib)
    - Include docstrings
    - Have `if __name__ == "__main__"` entry point

    IMPORTANT: Read repo/train_gpt.py first to understand:
    - What the model output file is named (may not be "final_model.int8.ptz")
    - How BPB is printed to stdout (need to know the format to parse it later)
    - What the exact eval methodology is

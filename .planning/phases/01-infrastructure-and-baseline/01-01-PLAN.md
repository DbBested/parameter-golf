  <action>
    1. Create scripts/tracking/log_experiment.py with these functions:

       `log_experiment(result_dir, run_id, config, metrics)`:
       - Appends a JSON-lines record to `{result_dir}/experiments.jsonl`
       - Record schema: {"timestamp": ISO format string, "run_id": str, "slurm_job_id": from SLURM_JOB_ID env var or "local", "config": dict, "metrics": dict}
       - config dict must include at minimum: seed, n_layers, n_dim, vocab_size, optimizer, quantization, compression, techniques_enabled (list)
       - metrics dict must include at minimum: val_bpb (float), artifact_bytes (int), code_bytes (int), model_bytes (int), wall_time_seconds (float), gpu_type (str), n_gpus (int)
       - Returns the record dict

       `load_experiments(result_dir)`:
       - Reads all lines from `{result_dir}/experiments.jsonl`
       - Returns list of parsed JSON dicts
       - Returns empty list if file doesn't exist

       Include `if __name__ == "__main__"` block that accepts `--result-dir`, `--run-id`, `--val-bpb`, `--artifact-bytes`, `--wall-time` via argparse and logs a record.

    2. Create scripts/tracking/query_experiments.py with these functions:

       `query_experiments(result_dir, sort_by="val_bpb", limit=None, filter_fn=None)`:
       - Loads experiments from experiments.jsonl
       - Sorts by metrics[sort_by] ascending (lower BPB = better)
       - Applies optional filter_fn(record) -> bool
       - Returns top `limit` results (or all if None)
       - Prints a formatted table to stdout: run_id | val_bpb | artifact_bytes | wall_time | seed

       Include `if __name__ == "__main__"` block with `--result-dir`, `--sort-by`, `--limit` args.

    3. Create scripts/storage/cleanup.py with these functions:

       `cleanup_checkpoints(checkpoint_dir, keep_recent=3, keep_best=True, results_file=None, dry_run=False)`:
       - Lists all *.ptz and *.pt files in checkpoint_dir sorted by mtime (newest first)
       - Identifies best checkpoint by lowest val_bpb from results_file (experiments.jsonl)
       - Keeps the `keep_recent` most recent files + the best checkpoint
       - Removes all others (or prints what would be removed if dry_run=True)
       - Prints summary: "Cleaned N checkpoints, freed X.X MB" or "Would clean N checkpoints, would free X.X MB"
       - Returns dict with keys: removed (int), freed_bytes (int), kept (int)

       Include `if __name__ == "__main__"` block with `--checkpoint-dir` (default: "checkpoints"), `--keep-recent` (default: 3), `--results-file` (default: "experiments/results/experiments.jsonl"), `--dry-run` flag.

    All scripts must:
    - Use `#!/usr/bin/env python3` shebang
    - Use only Python stdlib (json, os, time, pathlib, argparse, sys)
    - Have docstrings on all public functions
    - Handle missing files gracefully (no crash if experiments.jsonl doesn't exist yet)
  </action>

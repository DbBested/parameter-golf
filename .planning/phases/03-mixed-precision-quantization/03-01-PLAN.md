<objective>
Implement mixed-precision post-training quantization (int5 for MLP weights, int6 for attention) and per-layer reconstruction MSE logging, then submit a validation training run.

Purpose: The Phase 2 uniform int6 quantization produces an 18.49MB artifact -- 2.49MB over the 16MB cap. Switching MLP weights to int5 (clip_range=15) leverages zstd's better compression of the narrower value range (1.88x vs 1.51x ratio), saving ~2.5MB to fit under 16MB. Per-layer MSE logging provides visibility into quantization sensitivity for future optimization.

Output: Modified train_gpt.py with int5 MLP quantization + sensitivity logging, SLURM script, and a submitted training job.
</objective>

       # Per-layer quantization sensitivity (QUANT-05)
       if master_process:

           for name, param in base_model.named_parameters():

                   cat = _classify_param(name)
                   cr = 15 if cat == "mlp" else 31
                   q, s = quantize_intN_per_row(t, clip_range=cr)
                   if s.ndim > 0:

                   else:
                       recon = q.float() * s.float()
                   mse = (t - recon).pow(2).mean().item()
                   max_err = (t - recon).abs().max().item()
                   log0(f"quant_sensitivity {name} cat:{cat} int{5 if cat=='mlp' else 6} "
                        f"mse:{mse:.2e} max_err:{max_err:.4f} shape:{list(t.shape)}")
